# Banner horizontal: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** gerar banners de site, LinkedIn, Facebook e YouTube no tamanho exato, com texto e logo dentro da área segura, só com a opção de baixar.

**Architecture:**
- `artFormats` (`lib/mocks/studio.ts`) passa a ser a fonte única de cada formato: tipo, tamanho de geração, tamanho final e área segura.
- Funções puras em `lib/images/format-geometry.ts` calculam o recorte, a área segura e a posição da logo.
- `fitToFormat` (sharp) recorta e redimensiona.
- A rota gera em 2048x1152, aplica a logo na área segura e só então recorta.
- A UI troca as checagens de story por `hasCaption` e `isInstagram`.

**Tech Stack:** Next.js 16, sharp, Drizzle, OpenAI SDK, `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-31-banner-e-carrossel-design.md` (seção Banner).

- Destinos (largura x altura final):

  | id | Destino | Tamanho final | Área segura |
  | --- | --- | --- | --- |
  | `banner-site` | Banner de site | 1920x600 | |
  | `banner-linkedin` | Capa LinkedIn | 1584x396 | |
  | `banner-facebook` | Capa Facebook | 1640x624 | |
  | `banner-youtube` | Banner YouTube | 2560x1440 | 1546x423 central |

- Geração do banner em 2048x1152. A área segura padrão é a faixa de recorte menos 6% de cada lado. A logo tem no máximo 18% da largura e 30% da altura da área segura.

**Interfaces:**
- `type Box = { left: number; top: number; width: number; height: number }`
- `getFormatCrop(formatId): Box`: recorte central, no quadro gerado, com a proporção de `outputSize`.
- `getSafeArea(formatId): Box`, no quadro gerado:
  - com `safeAreaSize`: converte esse tamanho para a escala do recorte e centraliza;
  - sem `safeAreaSize`: o recorte reduzido em 6% de cada lado;
  - para posts: o quadro todo.
- `getLogoPlacement(safeArea: Box, logo: { width: number; height: number }, marginRatio = 0.05): { left: number; top: number }`: canto inferior direito **dentro** da área segura.
- `getLogoMaxSize(formatId): { width: number; height: number }`: o banner usa os limites da área segura. Os posts mantêm `0.3 × largura` e `0.12 × altura` do quadro, como hoje.
- `fitToFormat(image: Buffer, formatId): Promise<Buffer>`: `sharp.extract(getFormatCrop)` → `resize(outputSize, { fit: "fill" })` → PNG. A proporção do recorte é a mesma do destino, então nada distorce.
